# כפר גלובלי — צ'אט עולמי בלי מחסום שפה

כל אחד כותב בשפה שלו, והצד השני קורא בשפה שלו.

**האתר החי:** https://krmy1979.github.io/kfar-globali/

## מה יש באפליקציה
- מסך כניסה: שם, שפה (16 שפות), אישור גיל 18+ וכללי קהילה.
- חדרים: לובי, טכנולוגיה, תרבויות, שיתופי פעולה, לומדים שפות.
- שיחות פרטיות בין שני משתמשים.
- תרגום אוטומטי של כל הודעה לשפה של הקורא, עם כפתור "הצג מקור".
- הודעות קוליות עד 30 שניות: ההקלטה נשמרת, והדיבור מתומלל ומתורגם.
- דיווח על הודעה, חסימת משתמש, מחיקת הודעה שלי.
- ממשק בעברית ובאנגלית (שאר השפות מקבלות ממשק באנגלית).

## איך זה בנוי
- **אירוח:** GitHub Pages מתוך הענף `main`.
- **שרת:** Firebase, פרויקט `kfar-globali` — כניסה אנונימית (Authentication) והודעות בזמן אמת (Firestore).
- **אבטחה:** הכללים בקובץ `firestore.rules` (מפורסמים בקונסולת Firebase). שיחה פרטית נגישה רק לשני המשתתפים בה.
- **תרגום:** קודם המנוע המובנה של Chrome אם חבילת השפה מותקנת; אחרת שירות MyMemory החינמי (כ-5,000 תווים ביום לכל כתובת IP).

## מבנה הקבצים
- `index.html` — הדף
- `css/style.css` — העיצוב
- `js/config.js` — פרטי החיבור ל-Firebase (להחליף ב-`null` כדי לעבוד מקומית בלי שרת)
- `js/i18n.js` — רשימת השפות וטקסטי הממשק
- `js/store-local.js` — שמירה מקומית (מצב ניסיון בלי שרת)
- `js/store-firebase.js` — שמירה בענן
- `js/translate.js` — מנוע התרגום
- `js/app.js` — לוגיקת המסכים
- `firestore.rules` — כללי האבטחה של מסד הנתונים

## מגבלות ידועות
- זהות המשתמש היא לפי דפדפן. כדי לבדוק שני משתמשים צריך שני דפדפנים, חלון גלישה בסתר או טלפון.
- טקסט שנשלח ל-MyMemory עובר לצד שלישי, כולל בשיחות פרטיות.
- אין עדיין מסך ניהול לדיווחים; הם נשמרים באוסף `reports` ב-Firestore.
- אין עדיין תנאי שימוש ומדיניות פרטיות כתובים.
- התוכנית החינמית של Firebase מוגבלת לכ-50,000 קריאות ו-20,000 כתיבות ביום.
