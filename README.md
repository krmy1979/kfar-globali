# כפר גלובלי — צ'אט עולמי בלי מחסום שפה

כל אחד כותב בשפה שלו, והצד השני קורא בשפה שלו.

## מה יש בגרסה הזו (גרסת ניסיון מקומית)
- מסך כניסה: שם, שפה, אישור גיל 18+ וכללי קהילה.
- חדרים: לובי, טכנולוגיה, תרבויות, שיתופי פעולה, לומדים שפות.
- שיחות פרטיות בין שני משתמשים.
- תרגום אוטומטי של כל הודעה לשפה של הקורא, עם כפתור "הצג מקור".
- הודעות קוליות עד 30 שניות: ההקלטה נשמרת, והדיבור מתומלל ומתורגם.
- דיווח על הודעה, חסימת משתמש, מחיקת הודעה שלי.
- ממשק בעברית ובאנגלית (שאר השפות מקבלות ממשק באנגלית).

## איך מנסים
1. לפתוח את `index.html` ב-Google Chrome במחשב.
2. להיכנס בשם ובשפה (למשל עברית).
3. לפתוח את אותו קובץ בחלון Chrome נוסף ולהיכנס בשם אחר ובשפה אחרת (למשל English).
4. לכתוב בחלון אחד ולקרוא בשני. התרגום אוטומטי, בלי לחיצות.

## איך התרגום עובד
1. אם חבילת השפה של Chrome כבר מותקנת, התרגום נעשה על המחשב עצמו.
2. אחרת, טקסט ההודעה נשלח לשירות התרגום החינמי MyMemory וחוזר מתורגם. המגבלה שלו: כ-5,000 תווים ביום לכל מחשב.
3. ברקע Chrome מוריד את חבילת השפה, ומהפעם הבאה התרגום רץ על המחשב.

## מגבלות של גרסת הניסיון
- ההודעות נשמרות רק בדפדפן הזה. הן לא מגיעות לאנשים אחרים באינטרנט.
- טקסט שנשלח ל-MyMemory עובר לצד שלישי, כולל בשיחות פרטיות. לא לכתוב פרטים רגישים.
- איכות התרגום של MyMemory בינונית, ולא כל צמד שפות נתמך.

## מבנה הקבצים
- `index.html` — הדף
- `css/style.css` — העיצוב
- `js/i18n.js` — רשימת השפות וטקסטי הממשק
- `js/store-local.js` — שמירת ההודעות (מקומית). זה הקובץ שיוחלף בחיבור לשרת.
- `js/translate.js` — מנוע התרגום. זה הקובץ שיוחלף בתרגום בענן.
- `js/app.js` — לוגיקת המסכים

## השלב הבא: פתיחה לעולם
1. שרת הודעות בזמן אמת (למשל Firebase) במקום `store-local.js`.
2. תרגום בענן במקום המנוע של Chrome, כדי שיעבוד גם באייפון ובכל השפות.
3. העלאה ל-GitHub Pages.
4. מסמכי תנאי שימוש ומדיניות פרטיות, ומנגנון ניהול לדיווחים.
